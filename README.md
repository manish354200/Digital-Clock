# ⌚ Digital-Clock

## Overview

* A simple and interactive digital clock built using HTML, CSS, and JavaScript.
* This project displays the current time and can be extended to show different country time zones using dropdown selection.

## 🚀 Features

* Real-time clock updates every second.
* Supports 12-hour and 24-hour formats.
* Option to display day of the week.
* Dropdown to select and display any country’s time zone.

## 👨‍💻 Tech Stack

* HTML5 – structure
* CSS3 – styling (glassmorphism, responsive design)
* JavaScript (ES6) – logic and time handling
* Day.js / Intl.DateTimeFormat – for time formatting and time zone support
